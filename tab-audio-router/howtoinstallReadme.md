## How to Install (For Users)

You do not need Git or any coding knowledge to install this extension.

### 1. Download the Extension ZIP
1. Go to the [Tab Audio Output Router Releases page](https://github.com/rudhrojutharun/rudhrojutharunappstore/releases).
2. Under the latest release (**v2.1**), click **`tab-audio-router-v2.1.zip`** to download just this extension.

### 2. Extract the ZIP Folder
1. Open your **Downloads** folder.
2. Right-click **`tab-audio-router-v2.1.zip`** and select **Extract All...** (or extract it to a permanent folder like `Documents\ChromeExtensions\tab-audio-router`).
3. Keep this extracted folder in place—Chrome reads the extension files from this folder while you use it.

### 3. Load the Extension into Chrome
1. Open **Google Chrome** and type `chrome://extensions` in the address bar, then press **Enter**.
2. Turn on **Developer mode** using the toggle in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the extracted **`tab-audio-router`** folder (the folder that contains `manifest.json`) and click **Select Folder**.
5. **Tab Audio Output Router** will now appear in your extensions list and pin to your toolbar.

### 4. First-Time Audio Device Setup
1. Click the **Tab Audio Output Router** icon in the Chrome toolbar.
2. If device names show as locked or generic (`Audio Output 1`), click **Click here to allow access** to open the permission page in a new tab.
3. Click **Allow Audio Device Access** and choose **Allow** when Chrome asks for microphone permission.
4. Reopen the extension popup—your speakers, TV, and headphones will now appear by name so you can route any tab.
